# P1 checkpoint（共有用要約）

P1はJev要求の並列I/O、完了順回収、同じ不変入力の質問集約、役別RPSと待機列の設定、評価unitごとの状態表示を実装しています。H1.2は左動画・右上Jev評価・右下実行ログ。通常の全体状態帯はなく、hard error時だけ停止理由を表示します。人間のメモと元runは別記録です。

暫定設定は同時4・全体4RPS/burst4。役ごとの追加上限は任意指定、待機64fragment/768,000bytes、通常要求3unit/12質問/12,000文字、受付から5秒、再試行0。測定用最大8をコードの恒久上限にはしていません。C0とCD表示限定、確率合計1e-6、hard error時の新規送信全体停止、root・TTL・依存版・場の式を維持します。

P1最終回帰は351件、DOM125項目。実Jevの限定比較は同時2条件で確率合計0.99を検出して停止しました。同時4以上と質問集約の実効果、最適運用値、本番LIVEから二段リストへの直接配信は未確認です。模擬I/Oでの改善を実性能と混同しません。ユーザーはこのcheckpoint前に「P1の動作確認完了」と報告しました。未実測の性能や全素材の意味品質の確認までを含むとは解釈しません。

このリポジトリはソース・仕様・試験・合成生成器を配布対象とします。実動画・音声、ASR原文、実要求と応答、実run、人間レビューDB、予算、認可状態、秘密、モデル、venvは含めません。ローカルの詳細報告はそのまま保持し、この要約とは分離しています。新しいライセンス・外部素材の配布許可は付与していません。

## 試験の区分

通常pytestには私有の過去記録に依存する診断回帰もあります。ローカル移行ではそれらを含む全回帰を行います。新しいcloneで私有資料がない場合、その診断を実行しても資料不足となるため、結果を合格や実受入れにしないでください。公開用の合成生成器は `scripts/make_demo.py`。DOM harnessの一部もローカル診断資料を必要とします。移行時に実データをfixtureへコピーして公開することはしません。
